# Assume a Spherical Cow

A tasting tour of physics, in the spirit of Evan Chen's *An Infinitely Large Napkin*:
33 chapters, each a self-contained plate on one area of physics, with a prototype
example, the key results and why they hold, and a problem set graded by order of
perturbation theory.

## Building

The book uses XeLaTeX features (`fontspec`, `unicode-math`) and compiles with
[Tectonic](https://tectonic-typesetting.github.io), which fetches packages on demand.
First regenerate the chapter chart and the interactive map (standard-library Python),
then compile:

```bash
python3 -I scripts/build_map.py
tectonic -X compile main.tex
```

This writes `main.pdf` and `map.html`. Neither is committed: every push to `main`
runs `.github/workflows/build.yml`, which builds both and attaches them to the run
(Actions tab → latest run → *Artifacts*).

## Layout

| Path | Contents |
|---|---|
| `main.tex` | Book skeleton; chapters are listed with `\chap{name}` in progression order |
| `preamble.tex` | Fonts, colours, boxes, difficulty marks, math macros |
| `frontmatter/` | Title page, preface, advice for the reader (incl. the chapter map) |
| `chapters/` | One file per chapter |
| `backmatter/` | Appendix A (constants), B (where to go next), C (hints, in `hints/`), D (solutions, one file per chapter in `solutions/`) |
| `figures/`, `scripts/` | PNG figures and the stdlib-only Python script that generates them |
| `map.html` | Interactive chapter map for readers, generated by `scripts/build_map.py` from `scripts/map/template.html` |

## The chapter maps

There are two, both generated from the LaTeX sources by one script:

- `frontmatter/chart.tex`: the dependency chart on the "The map" page of the advice
  chapter, drawn like the one in the *Napkin*. Every box links to its chapter, and the
  arrows come from each chapter's `\buildson` line.
- `map.html`: a self-contained web page with the same graph, the tasting menus from the
  advice chapter, and a search across the whole book.

Rebuild both after editing chapters, then recompile the book:

```bash
python3 -I scripts/build_map.py
```

Chart box labels and positions are `CHART_LABEL` and `CHART` at the top of the script;
web labels and row order are `SHORT` and `ORDER`. A new chapter needs a `CHART` entry,
or the script puts its box at the bottom and warns.

## Conventions for writing a chapter

- Label the chapter `\label{ch:<name>}` and list its prerequisites with `\buildson{...}`.
- Open with `\chapterdek{...}` and a `prototype` box.
- Boxes: `prototype`, `keyidea`, and the theorem-like `definition`, `law`, `theorem`,
  `example`, `exercise`.
- Problems go in a `problems` environment, one `\prob{n}` each, in increasing difficulty:
  `\prob{1}` = O(ε) first order, `\prob{2}` = O(ε²) second order,
  `\prob{3}` = e^{-1/ε} nonperturbative. Mark results used later with `\core` and
  asides with `\aside`; add hints with `\hint{...}`.
- Figures are inline TikZ or pgfplots (the `asc` axis style is in the preamble), each in a
  `center` environment wrapping a `minipage{\linewidth}` so the picture and its
  `{\small ...}` caption never split across pages. Draw curves from the real formulas.
- End with a `reading` environment of `\rd{Book}{Why}` entries.
- Every problem needs a solution in `backmatter/solutions/<label>.tex` (named by the
  chapter label's suffix, e.g. `ch:sho` → `sho.tex`), written as `\sol{<label>}{<n>} ...`
  after a `\solchapter{<label>}` heading. Every `\prob{3}` also needs a hint in one of the
  `backmatter/hints/batch*.tex` files, in the same format.
- Cross-reference problems with labels (`\label{prob:...}`), never hard-coded numbers.
